Proposed semantic cover engine

12 geometry families, selected from report meaning.

The family is chosen from stable report metadata and content signals. Four modifiers create controlled variety, so the portal can show more than 20 distinct treatments without becoming visually inconsistent.

Base family

Primary category chooses the geometry

When two categories exist, the first category remains authoritative. The second category only adjusts a secondary detail, never the base identity.

Selection order

Deterministic routing

No generative decision runs inside WordPress. Selection happens during report processing and is stored with the report.

1Primary categorySelect semantic base family.
2Geography scopeGlobal globe or regional locator treatment.
3Report characterOutlook, benchmark, guide, survey, or scan.
4Evidence profileQuantitative density controls graphic intensity.
5Stable tie-breakHash gives variety without identity drift.

Small listing cards
