Usage

Only these variants render report content

Briefing and Signal entities retain their own components. Every report archive, search, topic, publisher, homepage, and fallback query uses one of these three.

Small

  • Archive grids and dense latest-report rows
  • Title, publisher, three pictogram facts
  • One-line summary

Medium

  • Search and contextual report listings
  • More metadata and three-line TLDR
  • No key-insight bullets

Large

  • Featured report and primary report spotlight
  • Vertical cover, full metadata, TLDR
  • Exactly two key-insight bullets

Behavior

Exact portal rules

“New” appears only when the WordPress publication timestamp is less than seven complete days old. It disappears at the seven-day boundary.

New badgeAge ≥ 0 and age < 7 × DAY_IN_SECONDS.
Global iconGlobe for global, worldwide, international, or multiple named markets.
Regional iconLocator pin for one country, city, region, or named local market.
Unknown geographyGeography fact is omitted; neighboring zones do not move.
OverflowClamp visible copy; preserve complete accessible link names and report page content.
