# MarketLense Agent-Engineering Benchmark

This corpus evaluates repository-local coding agents against 16 representative
MarketLense tasks. It is deliberately small and evidence-led: each task came
from a retained repository fix, while its expected behavior, relevant
components, regression checks, failure modes, and scoring metadata are held
outside the agent-facing prompt.

`cases.json` is the canonical corpus. It does not run agents, provision
worktrees, call providers, browse the web, or publish anything. The companion
quality script validates the corpus and scores a run record generated by the
agent runner or operator. It is not a generic benchmark framework.

## Corpus rules

The prompt presented to an agent is only `task_prompt`. Evaluators retain the
remaining case fields. In particular, do not expose `ground_truth`,
`verification`, `important_failure_conditions`, or `scoring` to the agent.

Every case references the commit that supplied its ground truth. For a
historical reconstruction, create an isolated disposable worktree at the
parent of that commit, then copy only the evaluator-owned regression test(s)
from the fixing revision into the worktree. This gives the agent the original
problem state without handing it the solution. Keep test additions or harness
adapters outside the agent-visible prompt.

```powershell
$caseFix = "<ground_truth.traceability.fix_commit>"
$caseRoot = Join-Path $env:TEMP "marketlense-agent-case"
git worktree add --detach $caseRoot "$caseFix^"
# Evaluator only: seed the named regression test from $caseFix, then run the
# case's required check in $caseRoot after the agent finishes.
```

Remove that disposable worktree with `git worktree remove <path>` when the
evaluation is complete. Do not use a production state directory, real browser
profile, credentials, or publishing target for a benchmark case.

## Scoring and run record

Correctness has a 70-point weight in every case. Relevant-file discovery,
scope control, and required checks contribute the remaining 30 points. One
point is deducted from the five-point scope budget for each modified file not
listed in `allowed_modified_files`; the scope component never becomes
negative.

An agent runner submits one object per attempted case. All ten measurements
below are required. When the runner cannot observe a measurement, use the
literal string `"unavailable"`; never substitute zero.

```json
{
  "schema_version": "1.0",
  "agent": {"name": "Codex", "version": "<runner-reported-version>"},
  "cases": [
    {
      "case_id": "ML-ARCH-001",
      "correct_completion": true,
      "files_discovered": ["<repository-relative-path>"],
      "files_modified": ["<repository-relative-path>"],
      "checks_executed": ["<exact-required-command>"],
      "tool_file_read_count": 18,
      "elapsed_seconds": 214,
      "token_usage": "unavailable",
      "estimated_cost_usd": "unavailable",
      "human_intervention_count": 0,
      "rework_count": 0
    }
  ]
}
```

`correct_completion` is an evaluator decision supported by the declared
verification checks. The scorer computes relevant-file recall, counts
irrelevant modified files, and matches executed checks by their exact declared
command. It aggregates duration, tool/file reads, tokens, cost, interventions,
and rework only when every scored record provides that measurement; otherwise
the aggregate records `unavailable`.

## Commands

Validate corpus structure, history references, ground-truth paths, and named
check paths:

```powershell
python scripts/quality/agent_engineering_benchmark.py validate --corpus benchmarks/agent-engineering/cases.json
```

Capture the reproducible current Codex corpus-integrity baseline:

```powershell
python scripts/quality/agent_engineering_benchmark.py baseline --corpus benchmarks/agent-engineering/cases.json --output benchmarks/agent-engineering/baselines/codex-current.json
```

The baseline binds the corpus hash and repository commit and validates all 16
cases. It explicitly records every agent-performance metric as unavailable: it
is an integrity baseline, not an invented Codex performance result.

Score a real externally captured run:

```powershell
python scripts/quality/agent_engineering_benchmark.py score --corpus benchmarks/agent-engineering/cases.json --run-record <agent-run.json> --output <scored-run.json>
```
