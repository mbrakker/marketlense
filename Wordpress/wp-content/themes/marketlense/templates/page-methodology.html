Methodology

How Market Lense creates each report digest

Our publishing pipeline uses deterministic extraction, schema validation, and structured prompting so every published digest is reproducible and auditable.

  1. Source ingestion: reports are imported from configured sources and fingerprinted by content hash.
  2. Evidence extraction: document structure, claims, metrics, and figure candidates are extracted and normalized into typed contracts.
  3. Validation: generated artifacts pass schema and grounding checks before publication is allowed.
  4. Digest rendering: output is rendered as executive-friendly HTML with section navigation, figure surfaces, and citation-aware summaries.
  5. WordPress publishing: digests, media, and taxonomy mappings are pushed via controlled publish orchestration.

Quality controls

Every run is logged with run/task/span identifiers, prompt hashes, and validation outcomes. Reports that fail extractability or evidence integrity gates are explicitly blocked from publishing.
