Methodology

How Market Bearing keeps published research connected to its evidence

The pipeline combines deterministic extraction, typed validation, and structured editorial shaping so every published report brief is reproducible, reviewable, and source-aware.

1. Ingest

Source acquisition

Reports are imported from controlled sources, fingerprinted, and staged so the pipeline can process a stable copy of the original material.

2. Extract

Evidence normalization

Document structure, metrics, claims, figures, and metadata are normalized into typed contracts before a report brief can be shaped for readers.

3. Validate

Schema and quality gates

Outputs must pass schema checks, content completeness checks, and explicit evidence-integrity gates before publication is allowed.

4. Shape

Executive report brief rendering

Approved evidence is composed into executive-friendly HTML with section navigation, visual surfaces, and context that supports rapid reading.

5. Publish

Controlled delivery

Only validated report briefs are published with taxonomy mappings, media assets, and archive placement that keep discovery surfaces aligned.

6. Observe

Logged and reviewable

Runs, tasks, prompt selections, and validation outcomes are logged so failures can be investigated and outputs can be reviewed later.

Quality controls

What keeps the output trustworthy

  • Reports that fail extractability or evidence-integrity checks are blocked instead of silently degraded.
  • Structured metadata and taxonomy mapping keep discovery pages consistent with what was actually published.
  • Prompt and validation events are retained so rendered output can be traced back through the pipeline.
