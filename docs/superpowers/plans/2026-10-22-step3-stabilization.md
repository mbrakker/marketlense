# Step 3 stabilization plan

## Scope

Stabilize the opt-in visual-authority Step 3 path at the current branch head without changing canonical publication behavior or adding new providers/services. Preserve the existing verified-fact contract, cache/idempotency boundaries, and bounded live evaluation requirements.

## Tasks

1. Add focused regressions before implementation for mixed terminal outcomes, malformed accounting, safe editorial-plan remapping, verified-fact evidence projection, source-page display/quote behavior, and factual-input isolation.
2. Restore independent verified-fact admission: account for every expected candidate exactly once, quarantine malformed/conflicting/unverified results individually, and retain the independently valid facts when coverage remains sufficient for the existing quality gates.
3. Remove arbitrary modulo assignment from verified editorial-plan remapping. Preserve only plan themes with unambiguous verified bindings and fail closed with a typed coverage error when the remaining plan cannot support the existing downstream minimum.
4. Preserve verified-fact provenance without presenting verifier analysis or synthetic statements as publisher quotations. Reuse the existing source-pack field and span resolver; keep authoritative pages/source identity and verify downstream quote/reference behavior.
5. Trace the DoubleVerify key-figure path against the retained artifact and source bindings. Change it only if an authoritative single-value representation is demonstrably lost; otherwise record the composite-metric limitation.
6. Run focused tests, provider-free Criteo/Adjust/DoubleVerify and mixed Algolia replay, then bounded live editorial generation and full PDF review if credentials and retained artifacts are available. Run the hosted CI format/tests/release-evidence checks after committing. Do not publish or promote canonical facts.
7. Update the existing Step 3 evidence report and backlog status only with measured results, including mutually exclusive outcomes, coverage, source review, calls/tokens/cost/latency/cache reuse, and residual limitations.

## Verification gates

- No unaccounted, duplicate, unexpected, malformed, or conflicting visual result can enter verified-fact authority.
- Valid facts are admitted independently of unrelated unresolved candidates, subject to existing minimum insight/editorial coverage.
- No arbitrary fact is assigned to an unmatched editorial theme.
- Synthetic verified-fact projections are not exposed as exact publisher quotations.
- No unsupported numeric enrichment or canonical artifact/publication mutation is introduced.
- Hosted CI and the required source-PDF editorial review pass before claiming Step 3 readiness; otherwise report PARTIAL/FAIL honestly.
