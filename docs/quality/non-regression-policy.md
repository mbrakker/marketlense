## CI Gates

The CI workflow enforces:

- formatting: `python scripts/ci/check_formatting.py`
- typing: `python scripts/ci/run_type_check.py`
- forbidden patching: `python scripts/ci/check_forbidden_patching.py`
- tests + coverage report
- coverage thresholds: `python scripts/ci/check_coverage.py`
- mutation thresholds: `python scripts/ci/run_mutation_gate.py --json-out mutation_results.json`
- non-regression comparator: `python scripts/ci/check_quality_regression.py`

## Docpack Regression Metrics

For the golden corpus, the comparator enforces non-regression for:

- pack presence rate
- pack non-empty rate
- schema-valid rate
- evidence reference integrity rate
- per-pack present/non-empty/schema-valid rates

Any drop below baseline fails CI.

## Candidate Extraction Regression Metrics

For the golden candidate corpus, the comparator enforces non-regression for:

- non-empty candidate pack rate
- mean candidates per report
- mean chart candidates per report
- mean table candidates per report
- valid bbox rate
- crop-path coverage rate
- preview-text coverage rate

Any drop below baseline fails CI.

## Prompt Fixture Corpus Regression Metrics

For the prompt dry-run fixture corpus, the comparator enforces non-regression for:

- total runtime across the corpus, with built-in jitter tolerance for render timing noise
- total token budget per family and corpus
- OCR call count per family and corpus
- browser attempt count per family and corpus
- estimated model cost per family and corpus

The gate also fails when the active prompt namespace set or family set changes without a refreshed committed baseline.
Each corpus measurement performs one unmeasured warm-up dry run first, excluding
one-time file-cache and policy-registry initialization from the render-runtime
metric while preserving the fixed measured iteration count.

Approved temporary regressions must be recorded in:

- `docs/quality/prompt_fixture_corpus_allowlist.yaml`

Each allowlist entry requires:

- `pattern`
- `owner`
- `reason`
- `expires_on`
- `max_delta_absolute` and/or `max_delta_percent`
