# MarketLense Product Overview

> **Documentation type:** Current reference
> **Canonical topic:** Product overview
> **Update trigger:** Supported product capability changes.

MarketLense turns source reports into validated, source-backed editorial artifacts. It acquires report material from configured sources, extracts text and visual candidates, produces structured analysis and HTML, and can publish approved artifacts to WordPress.

The public product is organized around Reports, Topics, Signals, Briefings, and Publishers. Reports are the source-backed unit; Topics organize editorial domains; Signals and Briefings reuse validated projected evidence; Publishers describe source organizations. Sources, runs, validation, publishing readiness, and cost are operator-facing surfaces.

MarketLense publishes approved pipeline artifacts and projections. WordPress is a publication layer: it does not synthesize new report intelligence at request time. See [editorial output](editorial-output.md) and [WordPress operations](../ops/wordpress.md).
