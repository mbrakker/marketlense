# Market Bearing Brand Specification

## Canonical Assets

- Wordmark: the existing `[ml_brand_logo]` shortcode rendered by `marketlense-core` is the canonical logo. Header and footer must reuse it rather than redraw or replace it.
- Product UI reference: the production WordPress site at `http://marketlense.medianewsonline.com/` and the block theme in `Wordpress/wp-content/themes/marketlense/` define the current visual vocabulary.
- No new illustration, icon set, or decorative imagery is required for the homepage refresh.

## Design Tokens

- Brand navy: `#082b54`
- Signal blue: `#0867d7`
- Support blue: `#d9ebff`
- Cool background: `#f3f7fc`
- Primary text: `#10233d`
- Secondary text: `#586b82`
- Muted text: `#71839a`
- Subtle border: `#d5e0ec`
- Editorial type: `Georgia, "Times New Roman", serif`
- Interface type: the theme's existing sans-serif stack

## Interaction Language

- The line ending in a dot is the primary brand signal.
- Navigation hover, keyboard focus, and current-page states use the line-and-dot signal without a filled highlight.
- Elevation is quiet: white surfaces, subtle cool borders, and navy-tinted shadows.
- Motion is limited to short opacity, color, border, shadow, and small translate transitions, with reduced-motion support.

## Voice

Market Bearing is authoritative, evidence-led, editorial, and restrained. Interface changes must improve hierarchy and confidence without adding promotional decoration or fabricated content.
