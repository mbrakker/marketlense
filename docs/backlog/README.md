## Shared GPT6 Luna rules retained from original catalogue

- Work on one verified outcome/slice and prerequisites at a time. Read current HEAD, relevant root/subtree `AGENTS.md`, code, contracts, configuration and existing tests before changing behavior.
- Source-confirmed defects are not necessarily measured production incidents. Hypotheses require compatible frozen before/after evaluation; proposed numeric thresholds are targets, not observed results.
- Reuse services for I/O, generators for domain semantics, orchestrators for retries and workflows, and existing typed contracts/validators. Version persisted or public contract changes; preserve original source, page, content-hash and lineage identities.
- Tests should exercise the canonical boundary with external I/O replaced by recorded/fake responses, covering success and important failure/restart paths. Never claim a check passed if it was not executed.
- Freeze input sources, model/prompt/config and validation criteria when comparing quality, reliability, elapsed time or cost. Include failures, abstentions, attempts, tokens and all repair work in denominators; offline replay does not prove live quality.
- Autonomous processing ends at immutable `awaiting_review` unless separately approved through existing release policy. P6 independent human editorial acceptance, E15 human-judged visual completeness and A21 first-attempt readiness are separate safeguards; temporary sandbox HTTP remains intentional.
- Record producer SHA, exact checks/results, unrun checks, cohort identity, changed files, residual uncertainty and rollback. Parent outcome closes only when every criterion passes.
